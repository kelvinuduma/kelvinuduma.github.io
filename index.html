ISM Code ↔ NIST CSF 2.0 Crosswalk

Case Study: MSC-FAL.1/Circ.3/Rev.3 tells DPAs and ship managers to structure maritime cyber risk management around a five-step framework mirroring the NIST Cybersecurity Framework — but never says what each control looks like inside an actual ISM Code Safety Management System. This closes that gap: 21 NIST CSF 2.0 subcategories across all six functions, mapped to ISM Code sections, MSC.428(98), and MSC-FAL.1/Circ.3/Rev.3, each with a plain-English note on what it looks like on the vessel.

Impact: A citable, filterable reference for DPAs, ISM and ISPS compliance officers, and maritime cyber consultants. Six rows carry no strong ISM equivalent and are flagged as gaps rather than smoothed over. Published open source under MIT.

Live tool: kelvinuduma.github.io/ism-cyber-crosswalk  ·  Source
